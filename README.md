## 🛠 How to Run Locally

1. **Clone the repository:**
   ```bash
   git clone https://github.com/MOHSIN777333/Projects-HTML-CSS-JAVASCRIPT-.git
   ```

2. **Navigate to project folder:**
   ```bash
   cd Projects-HTML-CSS-JAVASCRIPT-
   ```

3. **Open any project folder aur index.html ko browser mein open kare**

4. **Alternatively, bas double-click kare index.html file ko:**
   - Quiz App → `Quiz App/index.html`
   - Color Palette → `Color Palette/index.html`
